# 字型來源與授權

- `jf-openhuninn-2.1.ttf`：justfont [jf open-huninn](https://github.com/justfont/open-huninn-font/tree/master/font)，未修改原始字型。完整著作權、保留名稱與 SIL Open Font License 1.1 見 `OFL-huninn.txt`（上游 LICENSE）。
- `Montserrat.ttf`：[Google Fonts Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) 的直立可變字重版本，未修改原始字型。SIL Open Font License 1.1 見 `OFL-Montserrat.txt`。

CSS 將 Montserrat 限定於拉丁字符範圍，中文回退至 jf open 粉圓；font-display: swap 保留字型載入期間的備用字體。所有檔案由本網站提供，無外部字型連線。
